# Seminario de Profundización en Inglés

Plataforma web interactiva y bilingüe (español / inglés) para el syllabus de 19 sesiones dirigido a estudiantes de quinto semestre.

## Cómo abrirla

1. Descarga y descomprime el archivo ZIP.
2. Abre la carpeta `seminario-profundizacion-ingles`.
3. Haz doble clic en `index.html` para abrir el sitio en tu navegador.

No requiere instalación, servidor, base de datos ni proceso de compilación. Está construida con HTML, CSS y JavaScript nativos.

## Funcionalidades

- Selector de idioma español / inglés.
- Diseño adaptable a computadores, tabletas y teléfonos.
- Programa académico completo de 19 sesiones.
- Búsqueda por título, tema o actividad.
- Filtros por enfoque de aprendizaje.
- Seguimiento de sesiones completadas, guardado en el navegador mediante `localStorage`.
- Secciones de descripción, objetivos, resultados de aprendizaje, metodología, evaluación, proyecto final y recursos.
- Accesibilidad básica: navegación por teclado, etiquetas semánticas y soporte para movimiento reducido.

## Archivos

- `index.html`: estructura y contenido de la plataforma.
- `styles.css`: diseño visual y reglas responsive.
- `app.js`: traducciones, programa de sesiones y funcionalidades interactivas.

## Personalización

Puedes editar los textos y actividades de cada sesión en el arreglo `sessions` del archivo `app.js`. Las traducciones generales están en el objeto `translations` del mismo archivo.

**Nota:** la preferencia de idioma y el progreso se guardan localmente en el navegador del usuario. No se sincronizan entre dispositivos ni entre navegadores.
